# Niak Comfort — carte (dépôt archivé)

**La carte est désormais incluse dans [l’intégration Niak Comfort](https://github.com/Niakman13/niak-comfort-integration).**

Installez seulement l’intégration : la carte est disponible sur vos tableaux de bord sans rien déclarer, sous le nom « Niak Confort ». Si vous aviez installé ce dépôt dans HACS, vous pouvez le supprimer.

Le code de la carte se trouve maintenant dans le dossier [`card/`](https://github.com/Niakman13/niak-comfort-integration/tree/main/card) de l’intégration. Ce dépôt est conservé en lecture seule pour l’historique.
